# 代码审查流程

## 获取变更

审查以下变更：
!`git diff HEAD`

## 检查清单

1. **逻辑正确性**：算法是否正确，边界条件是否处理
2. **安全风险**：SQL 注入、XSS、敏感信息泄露
3. **性能**：是否有 N+1 查询、不必要的循环
4. **测试**：新功能是否有对应测试，测试是否断言了行为而非实现
5. **风格**：是否符合项目 ESLint/Prettier 配置

## 输出格式

- ✅ / ⚠️ / ❌ 每个检查项
- 具体行号引用
- 改进建议（如有）
